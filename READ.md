# Banking Management System

A beginner-friendly Banking Management System built using C.

## Features
- Create Account
- View Accounts
- Search Account
- Deposit Money
- Withdraw Money
- Transaction History
- Save Account Records

## Concepts Used
- Structures
- Functions
- Loops
- Switch Case
- File Handling

## How to Run

gcc main.c -o bank.exe

.\bank.exe
